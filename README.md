# 3D 迷宫探险 (3D Maze Adventure)

一个基于 Three.js 构建的 3D 迷宫探索网页游戏。穿过程序随机生成的绿色迷宫，寻找终点的城堡！

## 🎮 游戏特色

- **3D 第一人称视角**：沉浸式的探索体验，流畅的鼠标视角控制。
- **随机生成**：每次刷新页面都会生成全新的迷宫布局，永远不会重复。
- **小地图系统**：左上角实时显示卫星俯视图（小地图），帮助你确认方位。
- **卡通风格**：明亮友好的视觉效果，拥有鲜艳的绿色墙壁和风格化的终点城堡。
- **碰撞检测**：平滑的墙壁碰撞处理，带来顺滑的移动手感（你不穿墙！）。

## 🚀 如何运行

### 本地服务器（推荐）
项目已拆分为多个 ES Module（见下方「项目结构」），浏览器的安全策略会阻止通过 `file://` 直接加载模块，因此**需要通过本地服务器运行**：

1. 在当前文件夹打开终端（Terminal/CMD）。
2. 运行本地服务器（例如使用 Python 或 Node.js）：
   ```bash
   # 如果安装了 Python 3
   python -m http.server
   
   # or 如果安装了 Node.js (npx)
   npx http-server .
   ```
3. 在浏览器中访问 `http://localhost:8080`（或终端显示的端口）。

## 🏗️ 项目结构

代码按职责拆分为独立模块，样式、迷宫逻辑与三维渲染彼此解耦：

```
Bulbasaur/
├── index.html            # 精简的页面骨架，仅负责 DOM 结构与模块引入
├── css/
│   └── styles.css        # 全部界面样式
├── src/
│   ├── config.js         # 集中管理的游戏常量（尺寸、速度、玩家参数等）
│   ├── coordinates.js    # 网格 ↔ 世界坐标转换（唯一来源）
│   ├── maze.js           # DFS 迷宫生成（可注入随机数以便测试）
│   ├── connectivity.js   # BFS 连通性检测（保证迷宫可解）
│   ├── collision.js      # 纯 2D AABB 碰撞判断
│   ├── scene.js          # Three.js 场景、相机、渲染器与灯光
│   ├── mazeRenderer.js   # 将迷宫网格构建为墙体、地面与城堡几何体
│   ├── minimap.js        # 小地图正交相机与玩家标记
│   ├── player.js         # 指针锁定视角、移动、滑动碰撞与胜利判定
│   ├── ui.js             # 开始 / 胜利界面状态管理
│   └── main.js           # 组装各模块并驱动渲染循环
└── tests/                # 纯逻辑模块的单元测试
```

**设计要点**：`src/config.js`、`coordinates.js`、`maze.js`、`connectivity.js`、`collision.js` 均不依赖 Three.js，因此可在 Node 中直接运行与测试；坐标换算统一收敛到一处，消除了原先散落各处的重复计算；游戏状态集中在 `main.js`，不再依赖大量全局变量。

## 🧪 测试

迷宫生成、连通性、坐标转换与碰撞判断都有单元测试，使用 Node.js 内置测试运行器（无需安装任何依赖）：

```bash
npm test
```

覆盖内容包括：迷宫尺寸与边界、起点/终点开放、固定随机种子下生成结果可复现、任意种子下起点均可到达终点、坐标正反向转换一致，以及墙体、边界与滑动碰撞的判定。
